                                        📊 **Task 5 – Data Analysis on CSV Files**

📝 **Project Overview**

        This project analyzes a sales dataset stored in a CSV file using Python. 
        It reads the data, organizes it by category, calculates the total sales, and displays the results as a bar chart.

🎯 **Project Objective**

✔️ Read sales data from a CSV file.
✔️ Analyze the dataset using Pandas.
✔️ Calculate total sales for each product category.
✔️ Visualize the results with a bar chart.

🛠️ **Tools & Technologies**

🐍 Python
🐼 Pandas
📈 Matplotlib
💻 IDLE Python

📂 **Dataset Used**

         📄 Sample - Superstore 31.07.2026.csv

⚙️ **How the Program Works**

📥 Imports the required libraries.
📄 Reads the CSV dataset.
👀 Displays the first five records.
📊 Groups the data by Category.
➕ Calculates the total sales for each category.
📈 Creates a bar chart to compare category sales.
🖥️ Shows the output in the Python Shell.

✨ **Key Features**

📂 Reads CSV files efficiently.
📋 Displays dataset information.
📊 Performs category-wise sales analysis.
📉 Generates an easy-to-understand bar chart.
⚡ Simple and beginner-friendly Python program.

🚀 **Steps to Run**

📁 Place the Python file and CSV file in the same folder.
🖱️ Open task5.py in IDLE.
💾 Save the file.
▶️ Press F5 or click Run → Run Module.
📊 View the output and the generated chart.
